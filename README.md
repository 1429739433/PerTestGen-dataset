# PerTestGen-dataset

## 数据来源与使用说明

实验使用的 18 个学生技能画像为人工构造的模拟输入。试卷与 A4 评分来自归档的系统输出，专家评分来自人工评审记录。统计汇总表和交叉评分矩阵由逐卷评分与其他底表整理计算得到，属于派生数据。教材、课程标准和参考题库属于实验输入材料。

第三方材料仅供学习参考。请遵循原始来源的使用条款。教材、课程标准和题库原件的公开再分发以适用许可或权利方授权为准。

## Data provenance and use

The study used 18 manually constructed, simulated student skill profiles as experimental inputs. The test papers and A4 scores are archived system outputs. Expert scores come from human review records. Summary tables and cross-scoring matrices were derived from paper-level scores and other underlying records. The textbook, curriculum standards, and reference question bank served as input materials.

Third-party materials are used for learning and reference only. Their use is subject to the terms of the original sources. Public redistribution of the original files is subject to the applicable license or permission from the rights holder.
