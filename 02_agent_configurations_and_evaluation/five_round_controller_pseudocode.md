# 五轮控制伪代码

依据冻结验收记录重述 A1–A6 的调度。初评记为第 0 轮，最大修订轮次为 5。候选数、停滞策略与修订边界以每个画像冻结的运行配置为准。

```text
输入：教学素材 M，基础蓝图 B，画像 p，参考题库
T ← A1 构建并校核技能树，冻结 T 和基础蓝图映射
Bp ← A2 在 B 的整卷结构和必考约束内规划个性化题位
P0 ← A3 生成初稿，保存题干、答案和评分点
当前稿 ← P0
当前评价 ← A4 结构检查及五维初评
若达到全部阈值，输出当前稿
对轮次 1 至 5：
    从当前稿的已核实缺陷选择待修题位，纳入影响达标的否决项
    D、编辑要求 ← A5 诊断并提出具体修订及验收条件
    候选稿 ← A6 按允许的编辑范围修订试题、答案和评分点
    对候选稿执行 A4 复评，保存完整或待核状态
    控制器按当前配置核查结构、综合分、关键维度退化及已核实缺陷变化
    采用有效候选时更新当前稿；其余情况保留既有版本与候选记录
    若当前稿达到全部阈值，或触发本次配置的停止条件，结束循环
输出：最终保留稿、采用轮次、五维评分、综合分、遗留缺陷
```

达标要求为五维各 ≥80、综合分 ≥85、结构违约为空且关键评价已完成。四份未达标卷均有完整第五轮记录。
